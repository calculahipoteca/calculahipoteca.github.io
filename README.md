# CalculaHipoteca

Calculadoras gratuitas de hipoteca para España: https://calculahipoteca.github.io/

- `index.html`: cuota mensual, intereses y tabla de amortización
- `cuanto-me-presta-el-banco.html`: precio máximo según ingresos y ahorros
- `gastos-compra-vivienda.html`: ITP/IVA por comunidad autónoma y gastos de compra
- `amortizacion-anticipada.html`: reducir cuota o plazo

Sitio estático (HTML + CSS + JS sin dependencias) servido con GitHub Pages.
Mantenimiento mensual: actualizar el Euríbor en `index.html` y la fecha de `lastmod` en `sitemap.xml`.
